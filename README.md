# canal357 hassio-addons

Repositorio de add-ons para Home Assistant.

## Add-on: DSS VoIP Notifier (`dss_voip/`)

Notificador VoIP para Home Assistant. Permite realizar llamadas SIP como notificación.

- **Versión:** 4.2.0
- **Basado en:** [sdesalve/hassio-addons](https://github.com/sdesalve/hassio-addons/tree/master/dss_voip)
- **Arquitecturas:** aarch64, amd64, armhf, armv7, i386

### Instalación

1. En HA, ve a **Ajustes** > **Complementos** > **Tienda de complementos**
2. Menú (3 puntos) > **Repositorios** > añadir `https://github.com/canal357/hassio-addons`
3. Busca "DSS VoIP Notifier" e instala
